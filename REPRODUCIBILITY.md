# Reproducibility notes

## What is included here

This GitHub package contains the maintainable code snapshot, prompts, configuration files, manuscript source and lightweight source data.

## What is archived on Zenodo

The Zenodo package should contain the fixed manuscript-version archive, including processed spectra, replay outputs, CST-export summaries, source data and figure exports. Use the Zenodo DOI in the manuscript for version-locked citation.

## What is not included

Private API keys, local absolute paths, temporary cache files, Python bytecode and large native CST project files are not included. Large native CST projects can be deposited separately if licensing and file-size constraints permit.
